# 🍕 Pizza Sales SQL Analysis

## 📌 Project Overview

This project analyzes Pizza Hut sales data using **MySQL** to generate meaningful business insights from order, pizza, and sales data.

The analysis focuses on sales performance, customer ordering patterns, pizza popularity, revenue contribution, and category-level performance.

## 🎯 Business Questions

The project answers key business questions such as:

* What is the highest-priced pizza?
* What is the total revenue generated from pizza sales?
* How many orders were placed?
* What is the most commonly ordered pizza size?
* What are the top 5 most ordered pizza types?
* What is the quantity of pizzas ordered by category?
* How are orders distributed throughout the day?
* What is the category-wise distribution of pizzas?
* What is the average number of pizzas ordered per day?
* What are the top 3 pizza types based on revenue?
* What is the revenue contribution of each pizza category?
* How does cumulative revenue change over time?
* What are the top 3 revenue-generating pizzas within each category?

## 🚀 How to Run

1. Install MySQL.
2. Create or import the Pizza Hut database.
3. Load the required tables and dataset.
4. Open `pizza_sales_analysis.sql` in MySQL Workbench.
5. Run the queries sequentially to reproduce the analysis.
